# Demand Forecasting with Graph Neural Networks

This project predicts product demand using supply chain data and Graph Neural Networks.

Pipeline:

Raw Supply Chain Data  
→ EDA + preprocessing  
→ Graph construction  
→ GraphSAGE embeddings  
→ Time series forecasting  

Tech stack:

- Python
- PyTorch Geometric
- Scikit-learn
- Pandas
- Streamlit

notebooks/
